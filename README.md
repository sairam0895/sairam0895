## 📌 Featured Project

### 🤖 [SmartHire — AI-Powered L1 Screening Platform](https://github.com/sairam0895/SmartHire)

> Built for the Accion Labs Internal Hackathon

An end-to-end automated interview platform that replaces manual L1 screening calls with AI.

- **Teams & Slack bots** for candidate invites and scheduling
- **Browser-native voice/video interviews** using the Web Speech API — no plugins needed
- **Groq LLaMA 3.3 70B** for question generation and response evaluation
- **AWS S3** for interview recording storage
- Real-time **recruiter dashboard** with interview status tracking

`TypeScript` `Node.js` `Groq AI` `AWS S3` `Teams Bot Framework` `Slack Bolt`
